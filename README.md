# validation-bot

Panneau de validation des attentes Hermes EXE dans Claude Code. Il liste chaque attente avec quatre statuts (à valider, validé, à revoir, bloqué) et indique la prochaine attente à traiter.

Lecture seule : le mod ne lit ni n'écrit aucun fichier de Hermes, GLPI ou du serveur. Il garde les statuts dans la session.

## Installation

```bash
/plugin install validation-bot --marketplace youzurz/validation-bot
```

Dans la session, tape la commande ci-dessus, puis choisis la portée d'installation.

## Utilisation

Ouvre le panneau avec la commande `/validation-bot`.
